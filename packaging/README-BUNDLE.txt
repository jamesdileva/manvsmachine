Man vs. Machine — how to play
===============================

1. EXTRACT THIS WHOLE FOLDER FIRST.
   If you opened this file from inside the .zip download, close it,
   right-click the .zip > "Extract All", and use the extracted copy.
   (The game cannot run from inside the zip — its files aren't really there.)

2. Double-click ManVsMachine.exe.

3. Your browser opens at http://127.0.0.1:8000 — play!

Notes
-----
- Your save data is stored in manvsmachine.db next to the exe.
- If the game can't start, it explains why on screen and saves the details
  to manvsmachine-crash.log next to the exe — include that file if you ask
  for help.
- If port 8000 is busy (another copy running?), close the other copy first.
- No Python, Node, Docker, or internet needed. AI opponents come from the
  built-in library unless you configure real provider keys (see README).
